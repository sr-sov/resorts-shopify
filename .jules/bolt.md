## 2024-05-24 - LCP and INP Optimizations
**Learning:** For Shopify liquid templates, above-the-fold elements (especially large hero images) should use `fetchpriority="high"` instead of `loading="lazy"` to optimize the Largest Contentful Paint (LCP) time. Furthermore, user-generated or dynamic content like `alt` texts derived from variables should use `strip_html | escape` to prevent XSS. For scroll event listeners on layout containers, `requestAnimationFrame` and `{ passive: true }` should be used to prevent main thread blocking, ensuring Interaction to Next Paint (INP) stays under Shopify's 200ms threshold.
**Action:** Replaced `loading="lazy"` with `fetchpriority="high"` and added `strip_html | escape` to `alt` texts for hero images in `sections/hero.liquid`. Also optimized the nav scroll listener in `layout/theme.liquid` by using `requestAnimationFrame` and setting the event listener to passive.
